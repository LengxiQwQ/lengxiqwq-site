## ✦ 项目简介

**Car Rental Management System** 是我大学 **PRG2201 — Object-Oriented Programming** 课程中的小组项目，和我的好朋友 AWei 一起做的。

它是一个使用 **Java Swing + JDBC + MySQL** 开发的桌面汽车租赁管理系统，主要把课堂里学到的面向对象设计、数据库访问和分层结构真正放进一个完整业务流程里。

## ✦ 主要功能

- 管理车辆资料、库存和可用状态。
- 管理客户信息。
- 创建租赁记录并计算费用。
- 处理还车与车辆状态记录。
- 区分 Admin / Staff 两类使用场景。
- 查看租赁记录、统计报表与系统日志。
- 使用 DAO / Service / Model / UI 等分层组织代码。

这是一个课程 Assignment，所以现在已经归档，不会按长期产品继续维护。不过它保留了当时比较完整的一套 Java Swing + MySQL 项目结构，也算是我大学阶段比较有代表性的一次课程实践。
