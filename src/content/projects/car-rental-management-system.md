## ✦ 项目简介

**Car Rental Management System** 是大学就读期间独立完成的 Java 汽车租赁管理系统学术课题（Assignment）。

项目基于 Java 面向对象编程（OOP）核心设计思想构建，实现了车辆调度监控、客户租赁登记结算、报表统计与业务流转控制，完整展示了结构化需求分析、领域模型搭建与软件工程实践。
